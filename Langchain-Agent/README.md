## LangChain AI Agent Project

This project uses **LangChain** to build a single AI agent powered by the Gemini API.

### 1. Gemini API — AI Model
I chose Gemini because it offers a free API tier with limited usage.

Create your API key: https://aistudio.google.com/api-keys

### 2. Tavily API — Web Search
Tavily is used to search the internet and retrieve relevant results. It offers a free plan with limited usage.

Create your account: https://app.tavily.com/home

### 3. Weatherstack API — Weather Data
Weatherstack is used to retrieve current weather information for different cities.

Create your account: https://weatherstack.com/

**Note:** All three services offer free access with usage limits. You need to sign up and obtain the required API keys before running the project. Free-tier limits and availability may change.
